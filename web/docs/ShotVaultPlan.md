# ShotVaultPlan [N1]（内嵌可视化分镜规划面板）

节点内置直观的**可视化分镜规划 UI**：
1. 顶部支持一键导出合并成片（免重跑 H3 模型，含重抽 Take 与已开启的接缝修复）、上传 **已有视频 (`Shot 0`)** 并设置截尾秒数（设 `0` 则自动取视频末 `22` 帧转 `latent` 无缝进入无限流延展）。
2. 逐镜分镜卡片支持独立上传：**本镜参考图 (`<Picture 1..9>`)**、**参考视频 (`<Video 1..3>`)**、**参考音色 (`<Audio 1..3>`)**、**驱动音频**，调节时长、文戏(`1116`)/武戏(`1114`)/MV、`@cut@` / `@continue@` 切镜清零与固定机位数字人防劣化，并直接查看 `VALID` / `STALE` 状态与一键单镜重抽。
3. 也可点击「立即自动分段」把 `&时长& + @cut@/@continue@ + ===` 或双 `JSONC` 文本瞬间展开成可视化卡片。
