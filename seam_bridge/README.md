# Acheng Seam Bridge · 接缝修复

生成后、编码前修一处已知接缝。适用于能提供标准 ComfyUI `IMAGE` 的分段视频工作流，不依赖 H3、循环节点或 ShotVault。禁止自动移动切点：帧数、分辨率、帧率（由下游控制）和音频不变。

## 接线

| 场景 | 输入 | 输出 |
| --- | --- | --- |
| 分段循环 | `images` 接裁掉重叠区以后的当前段，`previous_tail` 接上轮已交付的末 4–8 帧，`join_frame=0`。首段、硬切可把 `is_continuation` 设为 false。 | `images` 接编码器；可从修后的段截尾供下一次接缝检测。 |
| 已拼成一批图 | `images` 接整批，`join_frame` 填 B 第一帧的零基序号，即之前各段实际交付帧数之和。 | 只修该点；不会搜索或修复其他接缝。多个已知接缝可以串联节点，序号不变。 |
| 1101 | `#1332` 的裁头后校色输出 → `images`；上一轮安全尾帧 → `previous_tail`；循环是否续段 → `is_continuation`。 | 将原先给 `#220 CreateVideo` 的多段画面替换为修后的输出。原音频线路可不动；原给 `#749` 的生成反馈也可不动。不要接裁头前发白的重叠区。 |

首段不接尾帧（或关掉 `is_continuation`）则直通。已知是硬切时应直接关掉该标志，不要仅依赖自动判断。可把 `diagnostics` 接文本显示，查看实际后端、白头估计长度、修改帧数、自动跳过原因和接缝平均 RGB 误差。误差是启发式评估，不是 ΔE，也不能证明动作正确。

## 模式

- `auto`：正常直通；优先尝试确实降低接缝差异的局部几何/校色；其他明显跳变或白头用 `auto_bridge_backend`，默认 OpenCV DIS。选择 RIFE 后若不可用，尝试 DIS 并记录原因。自动模式会拒绝未降低首缝误差或在修补区引入更大跳变的结果。
- `align_color`：稀疏双向 LK + RANSAC 估计 B→A 的平移、等比缩放和旋转，同时估计有界 RGB 增益/偏移；在 `release_frames` 内逐渐撤销。不对着白头做全段调色。
- `flow` / `rife`：保留 A 的最后一帧，以 B 的内部帧作另一端，替换其之前的 B 帧。默认最多 4 帧；检测到短白头时选它之后的第一个候选端点。白头超过预算直接跳过。手选模式仍受硬切保护，保护可关闭以便比较。不自动删帧。
- `off`：不做检测与修复。

依赖：ComfyUI 的 Python 环境需有 NumPy、PyTorch 和带 DIS 的 OpenCV；本机已有，无需另装。RIFE 可选，复用已加载的 [ComfyUI-Frame-Interpolation](https://github.com/Fannovel16/ComfyUI-Frame-Interpolation) 节点和本地权重。不会主动下载权重。把整个目录放进 `ComfyUI/custom_nodes` 后重启，搜索 **Acheng Seam Bridge**。RunningHub 自定义节点可用性未验证。

## 与 FuzzPuppy 的关系

[官网说明](https://www.fuzzpuppy.com/clip-merge)和[公开部署的压缩 Worker](https://www.fuzzpuppy.com/_next/static/chunks/4501.ea4743606b673a97.js)可核对。以下是本次实际读取到的部署版本；没有取得原始 TypeScript 仓库或可用 source map，压缩符号可能随部署改变。

| Worker | 实际做法 | 本节点的取舍 |
| --- | --- | --- |
| `eI` | 128 像素宽，A 尾/B 头各取 9 个时间点，约 0.5 秒内做最多 81 组粗比较；前 10 名加零裁剪基准进入相似变换精搜。评分含裁边惩罚。结构误差 < 0.38 且双向块匹配覆盖 > 0.08 才进入平滑。 | 已知接缝，不移切点；以 B 的干净帧选择桥接端点。使用不同的本地门槛。 |
| `eS` / `eT` 自动校正 | RGB 增益约束于 0.8–1.25、8-bit 偏移约束于 ±30；最多 384px 宽做三级时刻的稠密网格 LK 共识，边缘感知传播，并在 B 内再追踪三个时刻。合成一次坐标变形，约 4 帧重叠，最多 0.8 秒撤销修正。不兼容回落到硬切。 | 稀疏前后向 LK + RANSAC 做整体对齐，RGB 限幅后按帧释放。局部运动由单独的 DIS 桥接模式计算，不复制网站的多时刻 LK 场。 |
| `eT` RIFE / `V` | 先确定裁边及重叠时间线，渲染时从原片左右取端点，替换 3/5/7 帧；所有中间帧都直接由同一对端点推理。该分支不渲染自动校正的像素变形。Worker 实际模型族是 `rife422lite` ONNX（含优化变体），并非前端遥测标签里的 `rife-v4.26`。 | 仅替换 B 的坏头，不裁边、不改音频；可复用本地 RIFE，权重和时间线都与网站不同。 |

节点独立实现，不包含网站代码或模型，不宣称输出等价，也不上传视频。DIS 可能造成双影或形变；尤其是手、闪光、棍棒遮挡和动作不连续时，建议逐帧预览。有持续跨段色漂时，应在更上游做整段颜色管理。
